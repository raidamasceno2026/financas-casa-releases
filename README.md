# Deixe de Ser Pobre

App de finanças da família para Mac. Tudo fica no seu computador: nenhum dado financeiro vai para a internet.

## Instalar

1. Abra a [versão mais nova](https://github.com/raidamasceno2026/financas-casa-releases/releases/latest) e baixe o arquivo `.dmg`.
2. Abra o `.dmg` e arraste **Deixe de Ser Pobre** para **Aplicativos**.
3. Abra o app pela pasta Aplicativos.

Funciona em Macs com Apple Silicon e com Intel. O app é assinado e verificado pela Apple.

## Atualizações

Depois de instalado, o app avisa sozinho quando sair uma versão nova: "Atualização disponível". É só clicar para baixar e depois reiniciar. A procura automática pode ser desligada em Configurações → Atualizações.

Quem já usava o app com o nome antigo (Finanças da Casa) recebe a mudança de nome pela própria atualização: os dados continuam, e fica uma cópia de segurança antes da mudança.

Este repositório guarda só as versões do app.
